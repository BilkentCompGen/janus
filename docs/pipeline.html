The variant-classification step — four tools side by side

Graph construction is deliberately ignored here. This compares only how each tool turns a graph object into a named / classified variant — and where svp sits.

The spectrum: rust-mdbg stops before classification (assembly only) · svp does the least of the three callers (just a colour) · Cortex classifies confidence + genotype but defers semantic type to a reference · Severus is the only one with a real SV taxonomy — bought entirely with reference coordinates.

What svp's next stage can be — three layers on top of the colour tag

svp already has, per somatic bubble, both allele sequences + per-base (n,t) coverage. That hands you three classification layers, in increasing ambition. Read left → right: this is the order to build them, and it mirrors how the reference tools layer it (Severus: per-junction type → component type; Cortex: genotype → semantic type).

1Confidence / somatic call

Use the per-base (n,t) coverage already on each arm (CovRun{n_cov,t_cov}) to call each colour-2 bubble somatic vs germline vs artifact/repeat, with a VAF. Table-stakes for every caller — svp simply doesn't compute it yet.
borrows: Cortex model selection (variant / repeat / error) + Severus VAF & control-coverage gate
reference-freedata in simplify.bin
→

2Sequence-level allele typing

Diff the two arm sequences (anchor · normalArm · tumorArm · anchor):
= len, 1 base → SNV small Δlen → INS / DEL empty arm → pure ins/del arm ≈ revcomp(flank) → inversion tandem copy of anchor → DUP
borrows: Cortex — classify from the alleles themselves, no reference

3Graph-topology SV typing the frontier

Ask where the somatic arm's sequence reconnects in svp's own graph:
revcomp of a backbone segment → INV jump to distant backbone → DEL / DUP node in another component → TRA / BND chain of somatic bubbles → complex (chromothripsis-like)
The enabling primitive svp lacks: "does this somatic allele's sequence correspond to another node/path in the graph?" — a reference-free graph self-lookup. That, not coordinates, turns a local bubble into a typed rearrangement.
borrows: Severus topology → SV type, reimagined coordinate-free on svp's native sequence graph
research frontierneeds graph self-lookup

Layers 1–2 are reference-free and read only simplify.bin — immediate. Layer 3 is where the real research is, and where svp would genuinely differentiate from Severus: classifying SVs on the graph itself, without a reference index.
