Where the emissions go

Same 3.769 G core occurrences, split by what the signature turned out to be.

A “problem region” here is not annotation — it is measured from the FASTA by the parse itself: how many places in CHM13 produce the same core signature. A core seen at C places carries C× the depth in normal and tumour alike, so deleting one copy moves the ratio by 1/C and the dosage test cannot fire. Each build is scored on its own map, because the parse decides what counts as repetitive.

Precision is where HPC pays. At every threshold it is higher, and it gets there with 2.5–3.6× fewer calls — the false runs it removes are error signatures that used to survive the multiplicity gate. Note that neither build ever produces a call in a repeat class: a depleted node must have low coverage, and repeats do not.

Matched operating points

Aligned on the number of deletions found, so the two builds are doing the same job.

At the very loosest threshold (X=3, precision 1.6–3.3%, ~250 k calls) no-HPC finds 225/233 and HPC 223/233. The two it loses are both marginal in both builds. The cause is not signature merging — measured and refuted — it is geometry: HPC cores are longer in raw bp, a core is only depleted if it lies wholly inside the deletion, and the detector needs ≥3 connected depleted nodes.
