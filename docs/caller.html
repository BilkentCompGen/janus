What call does run_call(dir)

Reads refined.bin, walks its topology, and writes coordinate-free somatic calls. Uses only graph-intrinsic signals — colour, per-node normal/tumour coverage, connectivity, and (for the first time in the pipeline) the core bytes. No reference, no alignment.

The one rule: a somatic allele must involve at least one colour 2 (tumour-only) core — sequence present in the tumour reads and absent from the normal. Everything the caller emits is one of three structural shapes that a tumour-only allele can take in the graph:

PASS A

BUBBLE

Two arms diverge from a node and reconverge; ≥1 arm is tumour-only → a substitution or short indel. Typed by the spliced length Δ.

→
PASS B

BND

A tumour-only run bridges two shared anchors at ~full depth — a novel adjacency with no reference counterpart → DUP / INV / large-indel / translocation breakend.

→
PASS C

TIP

A tumour-only dead-end chain → an insertion-end / breakend candidate.

Passes run in this order, and each marks the nodes it uses in a consumed[] array so a later pass can't re-call them (bubbles win over breakends over tips). A seen set of canonical haplotype hashes collapses the forward / reverse-complement copy of every event. The caller is high-recall by design — it emits every qualifying structure and defers false-positive control to the downstream anchor stage.

Counts: hard whole-genome sim, mm=3, no blacklist (outputs/svp/wgs_mm3). CALL_MINSUP=3, SNP_EPS=2, CALL_JMAX=12, CALL_DEPTH_FRAC=0.30.

The graph it reads

Loaded from refined.bin into a CSR adjacency (out_off/out_nbr, in_off/in_nbr) plus per-node arrays. live_out[v]/live_in[v] = out/in degree.
colour 1 — normal-only colour 2 — tumour-only (candidate somatic) colour 3 — shared (reference-present anchor)
fieldmeaning · how the caller uses it
color[v]1 / 2 / 3 — the whole call logic keys off this
ncov[v] tcov[v]normal / tumour read depth — support (MINSUP), VAF, and the BND full-depth gate

This is the first stage to actually read the core bytes (via sp()/splice()). graph and refine only ever hashed them to a sig or carried them as opaque payload.

Shared machinery

Five helpers do the heavy lifting; the three passes are thin wrappers that call them.

trace_arm(g, start, arm) — walk one bubble arm to its sink

From start, follow the unique linear chain (out-degree 1, next node in-degree 1) collecting nodes into arm, until a node with in-degree ≥ 2 is reached — that's the reconvergence sink T. Returns T, or UINT32_MAX if the chain branches or dead-ends (not a clean arm).

code
uint32_t trace_arm(const G&g,uint32_t start,std::vector<uint32_t>&arm){
  arm.clear(); uint32_t cur=start;
  for(int s=0;s<1000000;s++){ arm.push_back(cur);
    if(g.live_out[cur]!=1) return UINT32_MAX; uint32_t nxt=one_out(g,cur);
    if(g.live_in[nxt]>=2) return nxt; if(g.live_in[nxt]!=1) return UINT32_MAX; cur=nxt; }
  return UINT32_MAX; }

reach_shared(g, consumed, seed, dir, jmax, run, mintc) — trace to a real anchor

From a colour-2 seed, step dir (−1 via in-edges, +1 via out-edges) always taking the highest-tcov neighbour. If that neighbour is shared → return it (the anchor). If it's another unconsumed tumour-only core → append to run, track the min tumour depth, continue. Give up after jmax steps. This is what threads a breakend through the repeat tangle to the nearest real locus on each side.

code
uint32_t reach_shared(...,uint32_t seed,int dir,int jmax,...){
  uint32_t cur=seed;
  for(int s=0;s<jmax;s++){
    // scan neighbours in `dir`; pick best shared (bs) and best tumour-only (bt) by tcov
    if(bs!=UINT32_MAX) return bs;          // reached a shared (real) anchor
    if(bt==UINT32_MAX) return UINT32_MAX;  // no tumour continuation -> not a clean bridge
    run.push_back(bt); mintc=std::min(mintc,g.tcov[bt]); cur=bt; }
  return UINT32_MAX; }

sp() + splice() + arm_pathlen() — turn a node path into a length / sequence

sp(A,B) is a KMP match returning the longest suffix of A that is a prefix of B — i.e. the exact overlap of two adjacent cores (~85 bp at L5, but computed per-pair from the bytes). splice() concatenates a node path minus those overlaps → the allele sequence. arm_pathlen() sums seqlen − overlap along a path → its true spliced length. The signed difference of the two arms' path-lengths is the variant's size.

code
uint32_t sp(const uint8_t*A,uint32_t la,const uint8_t*B,uint32_t lb){ /* KMP: longest suffix(A)==prefix(B) */ }

long arm_pathlen(const G&g,uint32_t S,const std::vector<uint32_t>&arm,uint32_t T){
  long L=0; uint32_t prev=S;
  for(uint32_t c:arm){ uint32_t ov=sp(P(g,prev),g.seqlen[prev],P(g,c),g.seqlen[c]); L+=(long)g.seqlen[c]-ov; prev=c; }
  uint32_t ov=sp(P(g,prev),g.seqlen[prev],P(g,T),g.seqlen[T]); L+=(long)g.seqlen[T]-ov; return L; }

canon_key(s) — forward / reverse-complement dedup

Because every locus is parsed on both strands, each real event surfaces twice. canon_key hashes min(s, revcomp(s)) so the two copies collapse to one seen entry.

Typing & emission

long d = arm_pathlen(g,s,*alt,T1) - arm_pathlen(g,s,*ref,T1);         // signed spliced Δ
if(std::labs(d)<=SNP_EPS){ ty="SNP"; size=1; }
else if(d>0){ ty="INS"; size=d; }
else{ ty="DEL"; size=-d; }
vaf = arm_mean_tcov(alt) / min(tcov[s], tcov[T1]);                // tumour VAF estimate
emit_sigs(id, g, *alt);  // write the alt-arm core sigs -> calls.altsigs.bin

Both arms are marked consumed; the canonical haplotype splice(S · alt · T1) is checked against seen so the RC copy is dropped. 262,951 bubble calls (of 263,646 raw, pre-dedup).

PASS B BND → DUP / INV / large-indel / translocation

A large rearrangement doesn't form a clean bubble — it's a novel adjacency: a stretch of tumour-only sequence that joins two places in the reference that were never adjacent. The caller finds it by bridging two shared anchors through a tumour-only run.

Decision flow (for each unconsumed colour-2 seed v with tcov ≥ MINSUP)

1

reach both anchors

reach_shared(−1) → L, reach_shared(+1) → R. Both must land on shared cores, else skip.

→
2

full-depth junction

min tumour depth of the run ≥ DEPTH_FRAC · min(tcov[L],tcov[R]) — rejects low-cov error spurs.

→
3

not too long, unconsumed

|jrun| ≤ JMAX; none of its nodes already used.

→
4

emit breakend

BND, or BND_CNgain if anchor tcov/ncov ≥ 1.5 (copy-number gain).

uint32_t L=reach_shared(g,consumed,v,-1,JMAX,up,mintc);
uint32_t R=reach_shared(g,consumed,v,+1,JMAX,dn,mintc);
if(L==UINT32_MAX||R==UINT32_MAX) continue;                 // not a clean two-anchor bridge
uint32_t anc=std::min(g.tcov[L],g.tcov[R]);
if((double)mintc < DEPTH_FRAC*anc) continue;             // junction must run at ~full tumour depth
emit_sigs(id,g,jrun);  // the whole tumour run's sigs

Works inside the repeat tangle — no degree-1 requirement — which is why it recovers rearrangements that never linearise into a bubble. 19,676 BND calls. (The caller does not sub-type DUP vs INV — that's left to the anchor geometry.)

PASS C TIP → insertion-end / breakend candidate

A tumour-only chain that hangs off the graph with a free end — one side dead, the other reaching a junction.

trace_tip walks the chain until a junction; require all cores colour-2, tcov ≥ MINSUP, length ≤ 16, none consumed. Emits the tip sequence as an insertion-end candidate. 12,113 TIP calls — the noisiest source (many are unresolved error ends), which is why the downstream anchor stage filters them hardest.

Ordering, consumed[] & dedup

Three global structures keep the passes from stepping on each other.
mechanismeffect
consumed[K]every node a call uses is marked; later passes skip consumed nodes. Order = BUBBLE → BND → TIP, so the most specific shape wins a contested node.
seen (hash set)keyed by canon_key(spliced haplotype) — collapses the forward and reverse-complement copy of the same event.
colour gateevery emitted structure must contain a colour-2 core (no purely N/S/shared calls — those carry no somatic allele).

The caller optimises for recall, not precision: it deliberately emits marginal T/S bubbles, low-anchor breakends, and every qualifying tip. Distinguishing real from false — and giving each call a genome coordinate — is the job of anchor.cpp, the next stage.

Call breakdown (hard WG, mm=3)

These are coordinate-free — sets of cores, no genome position. anchor.cpp then maps each call's reference-present flanking cores onto ref.fasta, brackets the breakpoint, filters SNP-misfires, dedups, and re-types via geometry to produce the VCF.
