Every pruner preserves the somatic colour and junction signal almost perfectly. The only thing that separates them is COPY — the tumour/normal depth ratio measured on the shared backbone. The hybrid family that won the old bake-off got there by deleting that backbone. Tight footprints scored well and made duplications permanently uncallable.

Why the metric changed — four measured findings

All from probing refined.bin directly (probe_signal.log, probe2.log, probe3_inv.log). Nothing here was assumed.

1 · Moved sequence stays shared

In a coordinate-free sequence graph a translocated or dispersed-duplicated segment keeps its sequence, so its cores keep their identity. Measured interior: rTRA 99.6% shared, dDUP 99.8%, nrTRA 99.6%. Their entire signal is at the junctions — there is no colour signal to find.

2 · Junctions are novel bridges, not edges

The core spanning a novel joint is itself novel, so a junction is shared → novel* → shared, never a direct edge between two positioned cores. The old metric looked for the direct edge and so found none:

3 · A large inversion's interior is invisible

A read lying entirely inside a big inversion sees the reverse complement read backwards — byte-identical to the reference. Nothing can tell. Only boundary-spanning reads carry the strand-1 signal, so the interior signal decays with size. This is information-theoretic, not an algorithm failure. The boundary detector recovers it: 27/27 at 50kb+.

4 · normal-only is a first-class signal

Genuinely lost sequence turns the reference cores normal-only, cleanly: DEL and CUT interiors are 100.0% normal-only (median frac 1.000; 299/299 records ≥0.9). And refpos stores both strands (84.9M records = 42.4M positions × 2) — shared cores are 42,187,779 strand-0 vs 346 strand-1, while positioned tumour-only cores are 155,341 strand-1 vs 5,484 strand-0. Reverse-complement present only in tumour is an inversion.

The five detectors, and what calibrates each

Each threshold comes from a measured separation between signal and anti-signal — not a tuned constant.

primitiveapplies towhat it looks forsignalanti-signalfull-graphFP (random loci)

A record hits only if all of its expected primitives fire. The expected set comes from the record's (SVTYPE, ALT, OP_TYPE) — e.g. CUT→LOSS, COPYinv-PASTE→INVSIG+COPY+JUNC, CUT-PASTE→JUNC only.

Negative control — and the confound it caught

400 matched random loci: same span length, same expected signature, position shuffled away from any true event.

Final: 0/400 false positives on every one of the 29 graphs. But the first version of this metric scored 14–15/400 on the aggressively-pruned graphs, and that was a real bug in my metric, not in those algorithms: LOSS and INVSIG normalised by cores surviving in the graph. Delete enough shared backbone and the denominator collapses, so a handful of leftover error normal-only cores looks like a perfect deletion — an aggressive pruner could manufacture recall out of nothing. Fixed by normalising against reference positions, which are graph-independent and therefore identical across all 29 graphs. Without the control this would have silently inflated exactly the algorithms under test.

The inversion

Old recip70 (footprint overlap / union) against real recall, across the 27 algorithms scored on both.

The old metric is anti-correlated with real recall: Pearson , Spearman . It is equally anti-correlated with the copy signal () and with keeping anchors ().

This was not noise. recip = overlap/union rewards a tight footprint. The cheapest way to make a footprint tight is to delete the shared backbone around it. That backbone is exactly what carries the duplication depth signal and the anchors. So the metric paid algorithms to destroy the thing we need.

The five hybrids scored 398–401 and sit at 972–978 real. Everything that scored the "ceiling" 364 sits at 1201–1230.

Frontier — and the COPY cliff

Graph size against real recall. Hover for detail; the dashed line is the Pareto frontier.

There is a cliff between 1.78% and 2.47% of the nodes: recall jumps 979 → 1201. That is the point where the shared backbone survives in enough depth to measure a tumour/normal ratio. Below it, every duplication (DUP, dDUP, COPY-PASTE — 354 records) becomes permanently uncallable, whatever else is kept.

What to do

  • Retire recip70. At Pearson −0.998 against real recall it is not a weak proxy, it is a reversed one. Every conclusion from the previous bake-off that rested on it — including "the hybrids beat the full-graph ceiling" — is void.
  • Ship edgeseed (2.78%) or anchormin (2.62%), not a hybrid. They hold 98.4% / 98.3% of the full graph's recall at ~36–38× compression, with 0 false positives and anchors retained on 84% / 71% of recovered events. minsize (2.47%, 97.6%) is the knee if size dominates.
  • The shared backbone is load-bearing. The original instinct to delete "some but not all" shared cores was right, and the place it is unsafe is specifically the copied spans. A copy-aware pruner — keep backbone where tcov/ncov departs from 1 — should beat every algorithm here, and no algorithm in the bake-off tried it.
  • INS was never broken. 120/130 under GAIN, on every graph. The 0/130 was the metric.
  • Honest open problem: 177 records (12.6%) are unrecoverable from the full graph itself, so no pruner can fix them. Large inversions lose their interior signal for information-theoretic reasons, and 74 COPY records never show a ratio.
